# Valle Brote

## Descargar el juego para Windows

**[Descargar Valle Brote 0.2.2 · Windows de 64 bits](https://github.com/edelapaz/ValleBrote-Releases/releases/download/v0.2.2/ValleBrote-0.2.2-win-x64.zip)**

[Ver la versión más reciente y sus novedades](https://github.com/edelapaz/ValleBrote-Releases/releases/latest)

1. Descarga el ZIP y extrae **todos** los archivos a una carpeta donde tengas permiso de escritura.
2. Abre `ValleBrote.exe` y conserva la carpeta `ValleBrote_Data` y los demás archivos que lo acompañan.
3. El menú comprueba las versiones disponibles. Para instalar una actualización, usa **Guardar, cerrar y actualizar** cuando aparezca el aviso.

El juego funciona sin conexión. Necesitas Internet para comprobar versiones y descargar actualizaciones. Tus guardados permanecen en tu equipo; este repositorio no sincroniza partidas entre computadoras.

## Novedades de la 0.2.2

- Corregido el error de inicio por `DSTORAGE.dll`: ahora el ZIP incluye las bibliotecas DirectStorage completas.
- Descarga probada desde una carpeta nueva y vacía antes de publicarse.

- Avisos visibles durante 12 segundos.
- Accesos rápidos que muestran objetos disponibles.
- Movimiento e interacción con clic.
- Regalos diarios y cultivos basados en el reloj del valle.
- Actualizaciones firmadas con comprobación de integridad, copia de seguridad y reinicio automático.
- Corregido el acceso denegado del instalador en Windows.

Si descargaste la 0.2.0 o la 0.2.1 y el juego no abre, descarga y extrae el ZIP completo de la 0.2.2 en una carpeta nueva. Tu partida se conserva.

Los ZIP y `latest.json` se publican como adjuntos en **Releases**. El código fuente se mantiene en un repositorio privado. Este repositorio público contiene únicamente la información de distribución y los archivos compilados de cada versión.
